# Redux Toolkit Learning

This repository is dedicated to learning and practicing Redux Toolkit with React. It covers fundamental and advanced concepts of state management through hands-on examples and mini projects.

## Topics Covered
- Redux Fundamentals
- Redux Toolkit
- configureStore
- createSlice
- Actions & Reducers
- React Redux Hooks
- createAsyncThunk
- Async API Calls
- Global State Management
- Project Structure
- Best Practices

## Goal
To build a strong understanding of Redux Toolkit and apply it in real-world React applications.
